# 🎬 AfterCredits

**Your movies. Your memories. Your cinematic identity.**

AfterCredits is a Java-based desktop movie discovery and personal cinema management application designed to bring the movie-watching experience together in one place.

Built with **Java Swing, Spring Boot, PostgreSQL, and the TMDB API**, AfterCredits allows users to explore movies, discover new titles, manage personal watchlists, track their movie activity, and build their own cinematic identity through a modern, cinema-inspired interface.

### ✨ Key Features

- **Movie Discovery:** Explore popular, now-playing, and upcoming movies.
- **Live Movie Data:** Fetch movie information through The Movie Database (TMDB) API.
- **Movie Details:** View movie information, genres, ratings, and trailers.
- **Personal Watchlists:** Save and organise movies you want to watch.
- **User Authentication:** Register, log in, and manage user sessions.
- **My Cinema:** Keep track of favourites, watched movies, and personal activity.
- **Cinema Identity:** Build a personalised profile reflecting your movie interests.
- **Customisation:** Enjoy a cinematic interface with multiple appearance themes.
- **Offline Demo Mode:** Explore the application using a pre-seeded mock catalogue when live data is unavailable.

### 🛠️ Technology Stack

- **Frontend:** Java Swing, FlatLaf
- **Backend:** Java, Spring Boot
- **Database:** PostgreSQL, SQLite
- **Movie Data:** TMDB API
- **Authentication:** JWT, BCrypt, Google OAuth integration
- **Build Tool:** Maven
- **Data Handling:** Gson
